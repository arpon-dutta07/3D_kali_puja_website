# 3D Kali Puja website

An interactive Kali Puja and Diwali night for the web, in the same style as Pujo 2K26 (চক্ষুদান): one opening moment, then a scroll journey of chapters.

- **অমাবস্যার ১০৮ প্রদীপ** (opening): carry the flame across 108 lamps on the temple steps; at midnight they reveal Ma.
- **জবার মালা**: thread red hibiscus from a brass thala into a garland for Ma.
- **ভূত চতুর্দশী**: load-shedding night in an old North Kolkata house. Light the 14 lamps and the ghosts back off.
- **ছাদের দীপাবলি**: candles on the parapet, the akash prodip, a tubri, a phuljhuri, and the whole city lights up.

Static site: Vite + TypeScript, three.js, gsap, Lenis. No backend.

```bash
npm install
npm run dev
```
